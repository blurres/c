## C Programming Course Notes

#### Declaring variables
Data types define what kind of data a variable can hold and how much memory it needs.
```dataType varName;```
Initialization
```dataType varName = value;```

Example:
```int age = 72;   // Integer (whole number) ```
```float price = 499.9f;    // Floating-point (decimal)```
```double pi = 3.14159;    // Double precision floating-point ```
```char sex = 'F';   // Single character ```
